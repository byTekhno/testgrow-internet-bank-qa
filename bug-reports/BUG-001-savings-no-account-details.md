# BUG-001 Накопительные счета не открывают детали по клику на строку

**Статус:** New  
**Серьёзность:** Major  
**Приоритет:** High  
**Модуль:** Список счетов / Детали счета  
**Требование:** REQ15, ИБ-2  
**Окружение:** Windows 11, Google Chrome, TestGrow practice99 — {TEST}GROW BANK  
**Дата:** 2026-08-29  
**Тест-кейс:** TC-008 (smoke), TC-010–TC-012 (blocked для накопительных)

## Шаги

1. Войти в модуль {TEST}GROW BANK под **любым клиентом**, у которого есть накопительный счёт.
2. Открыть пункт меню **«Счета»** (ЭФ «Список счетов»).
3. Кликнуть по строке счёта типа **«Накопительный»**.
4. Повторить для других клиентов и других накопительных счетов.



## Ожидаемый результат

По **REQ15**: каждая строка таблицы кликабельна и ведёт на ЭФ «Детальная информация по счету» с данными выбранного счёта (тип, номер, остаток, валюта, раздел «Реквизиты»).

## Фактический результат

Переход на экран деталей **не выполняется** для счетов типа **«Накопительный»** — остаёмся на списке счетов.

**Закономерность:** дефект **системный по типу счёта**, не привязан к одному клиенту. Проверено на нескольких пользователях — у **всех** накопительные счета не открывают детали.


| Проверенные клиенты               | Накопительные счета              |
| --------------------------------- | -------------------------------- |
| Все клиенты (прогон пользователя) | Все проверенные — не открываются |

## Влияние на тест-кейсы


| TC     | Статус  | Комментарий                                      |
| ------ | ------- | ------------------------------------------------ |
| TC-008 | Fail    | Клик по накопительному не ведёт на детали        |
| TC-010 | Blocked | Нельзя проверить детали накопительного счёта     |
| TC-011 | Blocked | Нельзя проверить реквизиты накопительного (руб.) |
| TC-012 | Blocked | Нельзя проверить реквизиты накопительного (вал.) |


Для счетов типов **Текущий / Зарплатный / Счет кредитной карты / Депозитный** кейсы TC-010–TC-012 можно выполнять отдельно.
