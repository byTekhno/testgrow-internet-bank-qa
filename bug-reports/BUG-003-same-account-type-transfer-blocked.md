# BUG-003 Перевод между счетами одного типа одной валюты невозможен

**Статус:** New  
**Серьёзность:** Critical  
**Приоритет:** High  
**Модуль:** Перевод между счетами  
**Требование:** ИБ-3, REQ03, REQ05, REQ06  
**Окружение:** Windows 11, Google Chrome, TestGrow practice99 — {TEST}GROW BANK  
**Дата:** 2026-08-29  
**Тест-кейс:** TC-022 (smoke)

## Шаги

1. Войти в модуль под **любым клиентом**, у которого есть два счета **одного типа** в одной валюте.
2. Открыть **«Перевод между счетами»**.
3. Выбрать счёт списания и счёт зачисления **одного типа**, одна валюта.
4. Ввести допустимую сумму (например, **1000,00**).
5. Убедиться, что кнопка **«Перевести»** активна.
6. Нажать **«Перевести»**.
7. При необходимости проверить вкладку **Network** в DevTools.
8. Повторить для других типов счетов (Текущий → Текущий, Зарплатный → Зарплатный, Накопительный → Накопительный) и других клиентов.



## Ожидаемый результат

По **ИБ-3** (шаг 8), формулировка из ТЗ:

> Операция по переводу средств между счетами клиента на сумму Сумма перевода создана

Перевод между двумя счетами одного типа в одной валюте **должен быть возможен** (REQ03, REQ05, REQ06). TC-022 предполагает перевод между двумя **текущими** счетами (100.00 RUB).

## Фактический результат

Перевод **между счетами одного типа** одной валюты **не выполняется**:

- кнопка **«Перевести»** **активна**;
- после нажатия **ничего не происходит** — нет уведомления об успехе, нет сообщения об ошибке, остатки не меняются;
- в **DevTools → Network** при клике **отправляется запрос**, но UI не реагирует и операция не завершается.

**Закономерность:** дефект **системный** — воспроизводится у **всех проверенных клиентов**, если тип счёта списания **совпадает** с типом счёта зачисления.


| Проверка                | Результат                                        |
| ----------------------- | ------------------------------------------------ |
| Все проверенные клиенты | Перевод одного типа → одного типа не выполняется |
| Кнопка «Перевести»      | Активна                                          |
| Реакция UI              | Отсутствует                                      |
| Network (DevTools)      | Запрос уходит, операция не завершается           |


Перевод **выполняется**, если типы **разные** (например, Текущий → Накопительный), но с дефектом в уведомлении — см. [BUG-002](BUG-002-transfer-amount-question-marks.md).

## Примечание

REQ05 не запрещает зачисление на счёт того же типа. REQ04-1 исключает только **выбранный** счёт списания, а не весь тип счетов. Отказ в переводе между счетами **одного типа** противоречит ТЗ.
