# BUG-005 Список «На счёт» не фильтруется по валюте источника

**Статус:** New  
**Серьёзность:** Major  
**Приоритет:** High  
**Модуль:** Перевод между счетами  
**Требование:** REQ06, REQ23  
**Окружение:** Windows 11, Google Chrome, TestGrow practice99 — {TEST}GROW BANK  
**Дата:** 2026-08-30  
**Тест-кейсы:** TC-016, TC-034

## Шаги

1. Войти в модуль под **любым клиентом** с несколькими счетами в **разных валютах**.
2. Открыть **«Перевод между счетами»**.
3. В поле **«Со счёта»** выбрать счёт списания **любой валюты** (RUB, USD, EUR, CNY и т.д.).
4. Открыть выпадающий список **«На счёт»** и сравнить валюты счетов в списке с валютой выбранного счёта списания.
5. *(опционально)* Выбрать счёт зачисления в **другой валюте**, ввести сумму и нажать **«Перевести»**.

## Ожидаемый результат

По **REQ06** и **REQ23**:

- после выбора счёта списания в списке **«На счёт»** доступны только счета **в той же валюте**, что и счёт списания;
- допустимые типы — по **REQ05** (текущий, зарплатный, накопительный, кредитная карта, депозит);
- выбранный счёт списания исключён по **REQ04-1**.

Для любого выбранного источника в списке должны быть **только счета той же валюты**.

## Фактический результат

После выбора **любого** счёта в «Со счёта» фильтр REQ06 **не применяется**: в списке **«На счёт»** отображаются счета **всех валют** клиента (RUB, USD, EUR, CNY и др.), а не только валюты источника.

**Закономерность:** дефект **системный** — воспроизводится при **любом** выбранном «Со счёта», независимо от валюты и клиента.


| Проверка                   | Результат                                  |
| -------------------------- | ------------------------------------------ |
| Любой выбранный «Со счёта» | Фильтр REQ06 не срабатывает                |
| Список «На счёт»           | Счета всех валют клиента                   |
| Символ валюты у поля суммы | Корректен (REQ24)                          |
| Кросс-валютный перевод     | Отклоняется: «Валюты счетов не совпадают!» |


Символ валюты у поля суммы (**$**, **¥** и т.д.) определяется корректно (REQ24), но **фильтр списка зачисления по валюте не применяется**.

При попытке выполнить кросс-валютный перевод система **отклоняет операцию** с сообщением:

> Операция по переводу средств между счетами клиента на сумму … не была проведена!  
> **Причина: Валюты счетов не совпадают!**

То есть **бэкенд-валидация срабатывает**, но UI по-прежнему **нарушает REQ06** — пользователь может выбрать недопустимую пару счетов и узнает об ошибке только после нажатия «Перевести».

## Дополнительно

- Дефект на уровне **UI-фильтрации** списка зачисления; **серверная проверка** кросс-валютного перевода работает — операция не выполняется.
- С**истемный** — фильтр REQ06 не срабатывает при любом выбранном «Со счёта» (в т.ч. для TC-016 с рублёвым источником).

## Примечание

REQ06 запрещает перевод между счетами в разных валютах. Счета другой валюты **не должны отображаться** в списке «На счёт»; отказ на этапе отправки формы не компенсирует нарушение требования.
