# BUG-008 Отрицательная сумма: кнопка «Перевести» активна при ошибке валидации

**Статус:** New  
**Серьёзность:** Major  
**Приоритет:** High  
**Модуль:** Перевод между счетами  
**Требование:** REQ25, REQ26  
**Окружение:** Windows 11, Google Chrome, TestGrow practice99 — {TEST}GROW BANK  
**Дата:** 2026-08-30  
**Тест-кейс:** TC-019

## Шаги

1. Войти под любым клиентом с двумя счетами для перевода (разные типы, одна валюта).
2. Открыть **«Перевод между счетами»**, выбрать «Со счёта» и «На счёт».
3. В поле суммы ввести **отрицательное** значение (напр. **-9 635,54**).
4. Проверить маску поля, состояние кнопки **«Перевести»** и сообщение об ошибке.
5. Нажать **«Перевести»** (если кнопка активна).

## Ожидаемый результат

По **REQ25** маска `NNNNNNN.NN` — только цифры; знак «−» **не должен вводиться**.

По **REQ26** кнопка **«Перевести»** активна только при сумме, заполненной **по маске** REQ25.

При невалидной сумме кнопка должна быть **неактивна** (см. TC-021).

## Фактический результат

- в поле суммы **вводится** отрицательное число (нарушение REQ25);
- поле **подсвечивается красным**;
- отображается ошибка: **«Сумма перевода должна быть больше 0,00!»**;
- кнопка **«Перевести» активна** (нарушение REQ26);
- перевод **не выполняется** (серверная/клиентская валидация блокирует).

**Противоречие:** кнопка активна при сумме вне маски REQ25; пользователь может нажать «Перевести», хотя операция заведомо недопустима.


| Проверка              | Результат        |
| --------------------- | ---------------- |
| Ввод «−» / отриц. сумма | Допускается   |
| Кнопка «Перевести»    | **Активна**      |
| Сообщение об ошибке   | Есть             |
| Перевод               | Не выполняется   |


### Подтверждённый пример


| Поле        | Значение                                                          |
| ----------- | ----------------------------------------------------------------- |
| Клиент      | Тестов Николай Первый                                             |
| Со счёта    | `40817810511991911002` (Текущий, Рубль)                           |
| На счёт     | `40817810533709231005` (Накопительный, Рубль)                     |
| Ввод        | -9 635,54                                                         |
| Ошибка      | «Сумма перевода должна быть больше 0,00!»                         |
| Кнопка      | **Активна**                                                       |
| Результат   | Перевод **не выполняется**                                        |
