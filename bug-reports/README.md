# Bug Reports — TestGrow Internet Bank (practice99)

Здесь хранятся баг-репорты по результатам тестирования симулятора **{TEST}GROW BANK**.

## Как добавить баг

1. Протестируй сценарий в TestGrow (practice99).
2. Зарегистрируй дефект в **BugTracker** платформы («Создать ошибку»).
3. Создай файл в этой папке: `BUG-001-short-title.md` (или используй шаблон).
4. При необходимости добавь скриншот в `../screenshots/`.

## Файлы

| Файл | Описание |
|------|----------|
| `bug-report-template.md` | Шаблон баг-репорта |
| `bug-checklist.md` | Чек-лист областей для поиска дефектов |

## Пример имени файла

```
BUG-001-transfer-without-sufficient-funds.md
```

После тестирования добавь сюда найденные баги — так репозиторий будет выглядеть как полноценное QA-портфолио.
