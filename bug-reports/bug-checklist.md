# Чек-лист поиска дефектов

Используй при прохождении practice99. Каждый пункт — потенциальная область с заложенными ошибками.

| Область | REQ | Что проверить |
|---------|-----|---------------|
| Список счетов | REQ01 | Отображаются ли счета неразрешенных типов или скрыты допустимые |
| Список счетов | REQ02 | Корректность валют, включая швейцарский франк |
| Реквизиты | REQ17 | ФИО владельца для рублевых счетов совпадает с тестовыми данными |
| Реквизиты | REQ18 | Поля Beneficiary / SWIFT для валютных счетов |
| Перевод | REQ03 | Депозитный и кредитный счет в списке «Со счета» |
| Перевод | REQ04-1 | Счет списания присутствует в списке «На счет» |
| Перевод | REQ06 | Перевод между счетами в разных валютах |
| Перевод | REQ07-1 | Перевод при недостаточном остатке |
| Перевод | REQ07-2 | Лимиты 999999.99 / 1500 / 2000 / 12000 по валютам |
| Перевод UI | REQ20 | Исходное состояние формы и активность кнопки |
| Перевод UI | REQ24 | Символ валюты рядом с полем суммы |
| Перевод UI | REQ25 | Маска суммы NNNNNNN.NN |
| Перевод UI | REQ26 | Кнопка «Перевести» при неполных данных |
| Сообщения | ИБ-3 | Тексты «Данная операция невозможна» и успешного перевода |
