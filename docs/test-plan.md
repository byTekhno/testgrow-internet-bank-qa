# Тест-план: модуль «Интернет Банк» (practice99)

## 1. Цель

Проверить соответствие модуля «Интернет Банк» функциональным требованиям из `ibrequirements.docx`, с фокусом на перевод между счетами клиента.

## 2. Объект тестирования

- Симулятор **{TEST}GROW BANK** на платформе TestGrow
- Модули: авторизация, список счетов, детали счета, перевод между счетами

## 3. Документация

- ТЗ: `requirements/ibrequirements.docx`
- Тестовые данные: Google Sheets (15 клиентов, 121 счёт)

## 4. Стратегия

| Тип тестирования | Объём |
|------------------|-------|
| Функциональное | Сценарии ИБ-1, ИБ-2, ИБ-3; REQ01–REQ26 |
| Негативное | Недостаток средств, превышение лимита, невозможные операции |
| UI | Маска суммы, активность кнопок, тексты сообщений |
| Регресс | Остатки после успешного перевода |

## 5. Критерии входа

- Доступ к practice99 в TestGrow
- ТЗ и тестовые данные изучены
- Тест-кейсы подготовлены

## 6. Критерии выхода

- Все High-priority тест-кейсы выполнены
- Дефекты зарегистрированы в BugTracker
- Задание отправлено на проверку

## 7. Риски

- Скрытые баги в реквизитах и мультивалютных сценариях
- Граничные значения лимитов по валютам
- Клиент с швейцарским франком (ID 15) — проверка REQ02

## 8. Тестовое окружение

- Браузер: Chrome (актуальная версия)
- Платформа: TestGrow practice99
- Данные: тестовые клиенты из Google Sheets
