## 1. Введение

В данном документе описаны требования, предъявляемые к модулю **«Интернет Банк»** (далее — Модуль).

## 2. Постановка задачи

В рамках модуля «Интернет банк» должны быть реализованы следующие основные сценарии:

- **ИБ-1.** Отображение списка счетов
- **ИБ-2.** Отображение детальной информации по счету
- **ИБ-3.** Создание операции по переводу между счетами клиента

---



## 3. Сценарии использования



### ИБ-1. Отображение списка счетов

**Назначение:** отображение списка счетов клиента, отображение остатка по счетам в списке.

**Предусловия:** отсутствуют.

**Базовые шаги:**

1. Клиент в браузере вводит адрес Модуля и переходит по ссылке.
2. Отображается экран «Список счетов».
3. В списке счетов отображаются все клиентские счета заданных типов.
4. Для каждого счета из списка отображается: номер счета, тип счета, остаток по счету, валюта счета.
5. Каждая строка списка счетов является ссылкой на детальную информацию по выбранному счету (см. ИБ-2).

**Расширения сценария:**

- **1а.** Клиент выбирает в Главном меню Модуля пункт «Счета».
- **3а.** Если у клиента нет счетов заданных типов, на месте списка отображается сообщение:  
*«Счета отсутствуют. Хотите открыть новый счет?»*

---



### ИБ-2. Отображение детальной информации по счету

**Назначение:** отображение детальной информации по счету.

**Предусловия:** клиент находится на экране «Список счетов».

**Базовые шаги:**

1. Клиент выбирает счет из списка и кликает по нему.
2. Отображается экран «Детальная информация по счету».
3. На экране отображается:
  - тип счета;
  - номер счета;
  - остаток по счету;
  - валюта счета;
  - раздел «Реквизиты».

**Расширения сценария:** отсутствуют.

---



### ИБ-3. Создание операции по переводу между счетами клиента

**Назначение:** создание операции по переводу между счетами клиента.

**Ограничения:** перевод может быть осуществлен только между счетами в одной валюте.

**Предусловия:** открыт Модуль.

**Базовые шаги:**

1. Клиент выбирает в Главном меню пункт «Перевод между счетами».
2. Отображается экран «Перевод между счетами клиента».
3. Клиент выбирает счёт списания (Счёт №1).
4. Модуль обновляет список счетов зачисления.
5. Клиент выбирает счёт зачисления (Счёт №2).
6. Клиент указывает сумму перевода.
7. Клиент нажимает кнопку «Перевести».
8. Отображается сообщение:
  *«Операция по переводу средств между счетами клиента на сумму Сумма перевода создана»*

**Расширения сценария:**

- **2а.** Если у клиента нет двух счетов заданных типов:  
*«Данная операция невозможна»*
- **4а.** Если нет других счетов заданных типов в валюте Счёта №1:  
*«Данная операция невозможна. Выберите другой счет для перевода»*
- **8а.** Если остаток на счёте списания меньше суммы перевода:  
*«Недостаточно средств на счете»*
- **8b.** Если сумма перевода больше допустимой:  
*«Сумма перевода больше допустимой. Для осуществления крупных переводов необходимо обратиться в отделение банка»*

## 4. Требования к продукту



### 4.1. Требования к функционалу



#### REQ01 — типы счетов в списке

В списке счетов должны отображаться все счета клиента **только** перечисленных типов:

- Текущий
- Зарплатный
- Накопительный
- Счет кредитной карты
- Депозитный



#### REQ02 — валюты в списке

В списке счетов должны отображаться счета **только** перечисленных валют:

- Российский рубль
- Евро
- Доллар США
- Юань
- Швейцарский франк



#### REQ03 — счёт списания (типы)

При переводе для выбора счёта списания (Счёт №1) доступны только:

- Текущий
- Зарплатный
- Накопительный



#### REQ04 — список счетов зачисления

После выбора Счёта №1 Модуль определяет список счетов, на которые может быть осуществлен перевод.

- **REQ04-1.** Ранее выбранный Счёт №1 не должен отображаться в списке зачисления.



#### REQ05 — счёт зачисления (типы)

Для выбора счёта зачисления (Счёт №2) доступны только:

- Текущий
- Зарплатный
- Накопительный
- Счет кредитной карты
- Депозитный



#### REQ06 — счёт зачисления (валюта)

Для выбора Счёта №2 доступны только счета **в той же валюте**, что и Счёт №1.

#### REQ07 — проверка допустимости перевода

При нажатии «Перевести» система проверяет допустимость перевода.

- **REQ07-1.** Если остаток на счёте списания меньше суммы перевода — сообщение о недостаточности средств.
- **REQ07-2.** Если сумма перевода превышает допустимую — сообщение о превышении суммы.



#### REQ08 — настраиваемые лимиты

Допустимая сумма перевода — настраиваемый параметр, независимо для каждой валюты.

#### REQ09 — лимиты по умолчанию


| Валюта            | Максимум   |
| ----------------- | ---------- |
| Российский рубль  | 999 999,99 |
| Евро              | 1 500      |
| Доллар США        | 2 000      |
| Юань              | 12 000     |
| Швейцарский франк | 1 500      |

### 4.2. Главное меню



#### REQ10

Главное меню должно содержать пункты:

- Счета
- Перевод между счетами



#### REQ11

При выборе «Счета» — переход на ЭФ «Список счетов».

#### REQ12

При выборе «Перевод между счетами» — переход на ЭФ «Перевод между счетами клиента».

---



### 4.3. Экранные формы



#### ЭФ «Список счетов»

**REQ13.** Форма содержит таблицу со списком счетов.

**REQ14.** В каждой строке таблицы:

- тип счета;
- номер счета;
- остаток по счету;
- валюта счета.

**REQ15.** Строка таблицы кликабельна и ведёт на ЭФ «Детальная информация по счету».

#### ЭФ «Детальная информация по счету»

**REQ16.** Форма содержит:

- тип счета;
- номер счета;
- остаток по счету;
- валюта счета;
- раздел «Реквизиты счета».

**REQ17.** Реквизиты **рублевого** счета:

- ФИО владельца счета;
- БИК;
- наименование банка;
- корреспондентский счет.

**REQ18.** Реквизиты **валютного** счета:

- Получатель / Beneficiary
- Банк-корреспондент / Correspondent bank
- Счет в банке корреспонденте / Correspondent account
- SWIFT банка-корреспондента / Correspondent bank SWIFT
- Банк-получатель / Beneficiary bank
- SWIFT банка-получателя / Beneficiary bank SWIFT



#### ЭФ «Перевод между счетами клиента»

**REQ19.** Элементы формы:

- выпадающий список «Со счета»;
- выпадающий список «На счет»;
- поле «Сумма перевода»;
- кнопка «Перевести».

**REQ20.** Исходное состояние после открытия:

- «Со счета» = «Не выбран»;
- «На счет» = «Не выбран»;
- «Сумма перевода» — пусто;
- кнопка «Перевести» недоступна.

**REQ21.** Список «Со счета» — в соответствии с REQ03.

**REQ22.** Если «Со счета» не выбран — список «На счет» по REQ05, валюта не учитывается.

**REQ23.** Если «Со счета» выбран — список «На счет» по REQ05 и REQ06.

**REQ24.** При выбранном «Со счета» справа от поля суммы отображается символ валюты выбранного счёта.

**REQ25.** Поле «Сумма перевода» — маска `NNNNNNN.NN`, где N — цифра.

**REQ26.** Кнопка «Перевести» активна только если:

- выбран «Со счета»;
- выбран «На счет»;
- сумма заполнена по маске (REQ25).
