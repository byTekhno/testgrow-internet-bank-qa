# Тест-кейсы: список счетов

**Модуль:** Список счетов  
**Приложение:** {TEST}GROW BANK (TestGrow practice99)  
**Тестовые данные:** [test-data/clients.md](../test-data/clients.md)


| ID     | Название                            | Требование  | Приоритет | Тип     |
| ------ | ----------------------------------- | ----------- | --------- | ------- |
| TC-005 | Отображение допустимых типов счетов | REQ01       | P0        | UI      |
| TC-006 | Отображение допустимых валют        | REQ02       | P0        | UI      |
| TC-007 | Структура таблицы счетов            | REQ13-REQ14 | P0        | Позитив |

| TC-009 | Сообщение при отсутствии счетов     | ИБ-1 (3а)   | P1        | Негатив |


> **Прогон 2026-08-29:** TC-006 — **Pass** (REQ02 OK на **Тестове Николае Первом**; **Тестов Олег Второй** — Skipped из-за BUG-004). **BUG-004 (системный):** депозитные счета не отображаются у **всех** клиентов — TC-005, TC-007 **Fail**; TC-008 **Fail** (+ BUG-001); TC-009 **Skipped** у Олега Второго.
