# Результаты прогонов

После выполнения тест-кейсов создавай файл с датой, например `2026-08-29.md`.

## Формат

```markdown
# Прогон 2026-08-29

**Окружение:** Chrome, TestGrow practice99

| ID | Статус | Комментарий |
|---|---|---|
| TC-001 | Pass | |
| TC-002 | Fail | см. BUG-001 |
```

Статусы: **Pass**, **Fail**, **Blocked**, **Skipped**.
